# Telegram export compatibility

## Supported input

Telegram Archive Viewer currently targets **Telegram Desktop HTML exports**.

When exporting a chat in Telegram Desktop, choose a human-readable HTML export. The importer looks for files named:

```text
messages.html
messages2.html
messages3.html
...
```

The numeric suffix is sorted naturally so pages are processed in Telegram's intended sequence.

## Parsed data

The importer currently attempts to extract:

- Telegram message ID
- sender name
- exact message timestamp when present in the HTML `title` attribute
- date separator labels
- message text
- reply target
- forwarded-from information
- media type
- media path
- media title and status
- reactions

## Media

If Telegram exported the underlying media file, the viewer serves it through the authenticated `/media/...` endpoint.

If Telegram's HTML says that a file was not included in the export, the message metadata can still be imported, but the viewer cannot display a file that does not exist locally.

## Unsupported formats

The following are not currently supported:

- Telegram JSON export
- arbitrary HTML archives that are not generated by Telegram Desktop
- live synchronization with Telegram

## Future compatibility

Telegram's HTML structure is not an API contract and may change. The parser is intentionally isolated in `app/importer.py` so compatibility fixes can be made without changing the rest of the application.

If you report a parsing problem, provide the smallest possible **sanitized** HTML fixture. Remove names, usernames, phone numbers, message text, media, and any other private data unless the specific field is required to reproduce the bug.
